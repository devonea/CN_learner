그룹과 카드

  • 홈 화면 "+ 카드 붙여넣기"로 그룹을 만들고 카드를 한 번에 여러 장 추가할 수 있습니다.
  • 입력 형식: 간체[Tab]병음, 번체, 해석 — 한 줄에 카드 한 장. 해석 자리에는 콤마로 이어서 한자음이나 부가 설명도 자유롭게 넣을 수 있습니다 (예: 入住[Tab]rù zhù, 入住, 입주, 체크인하다 → 해석에 "입주, 체크인하다"로 표시).
  • 그룹 카드의 ✎ 아이콘으로 그룹 이름·설명을 수정하고, ↑↓ 아이콘으로 순서를 바꿀 수 있습니다.
  • 그룹 상세 화면에서 "카드 선택"으로 여러 카드를 한 번에 삭제하거나 다른 그룹으로 이동할 수 있습니다.

라이트너 학습 원리 (Box1~4)

카드마다 숙련도에 따라 Box1~Box4 중 하나에 속하며, 박스가 높을수록 복습 간격이 길어집니다 (분산복습 원리 — 잘 아는 내용일수록 뜸하게, 잘 모르는 내용일수록 자주 복습).

  • Box1 (당일): 새 카드가 시작하는 박스. "모름"으로 채점되면 항상 Box1로 돌아가고, 다음 복습 예정일이 즉시(당일)로 잡혀 같은 날 계속 다시 등장합니다.
  • Box2 (3일 뒤), Box3 (7일 뒤), Box4 (14일 뒤): "자신있음"으로 채점할 때마다 한 단계씩 올라가며, 그만큼 다음 복습일이 뒤로 늘어납니다.
  • "알듯말듯"은 현재 박스를 유지합니다 (승급도 강등도 아님).
  • 오늘 복습 예정(Due)인 카드가 하나도 없으면 라이트너 모드는 시작되지 않고 안내 메시지가 표시됩니다. 그래도 더 학습하고 싶다면 랜덤 모드를 이용하거나 새 그룹을 만들어보세요.

학습 모드

  • 라이트너 모드: 오늘 복습할 카드(Due)만, 박스가 낮은 카드부터 우선 노출합니다.
  • 한 번에 학습할 카드 수는 MY 설정에서 조절할 수 있습니다 (10장 / 15장 / 20장 / 전체, 기본값 15장). Due 카드가 설정한 수보다 많으면 그중 우선순위 높은 카드만 그 세션에서 학습합니다.
  • 랜덤 모드: 그룹 내 모든 카드를 무작위 순서로, Due 여부와 상관없이 학습합니다.
  • 카드를 탭하면 뒤집혀서 병음·번체·뜻이 나타나며, 모름 / 알듯말듯 / 자신있음 3단계로 채점합니다.

홈 화면에 설치하기 (오프라인 지원 포함)

파일을 더블클릭해서 직접 여신 경우(주소창에 file://로 시작), 크롬 보안 정책상 "홈 화면에 추가" 및 오프라인 캐싱이 제한됩니다. 아래처럼 무료로 호스팅하면 앱처럼 설치되고, 이후엔 인터넷 없이도 열립니다.

함께 받은 5개 파일(index.html, manifest.json, sw.js, icon-192.png, icon-512.png)을 모두 같은 폴더(저장소 루트)에 올려야 합니다. index.html 하나만 올리면 오프라인 캐싱이 동작하지 않습니다.

방법 A. GitHub Pages

  1. github.com에서 새 저장소(Public)를 만듭니다.
  2. 받은 5개 파일을 저장소 루트에 그대로 업로드합니다 (폴더 없이, 파일명 변경 없이).
  3. 저장소 Settings → Pages → Source를 "main" 브랜치로 설정 후 저장합니다.
  4. 몇 분 뒤 https://내아이디.github.io/저장소명/ 주소가 생성됩니다.
  5. 이 주소를 크롬 모바일로 열고 메뉴에서 "설치" 또는 "홈 화면에 추가"를 누릅니다.

방법 B. Netlify Drop (계정 없이 가능)

  1. app.netlify.com/drop 접속
  2. 5개 파일이 담긴 폴더 전체를 화면에 끌어다 놓습니다.
  3. 생성된 https 주소를 크롬 모바일로 열고 "홈 화면에 추가"를 누릅니다.
  4. 계속 사용하려면 무료 계정으로 사이트를 "Claim"해두는 것을 권장합니다.

한 번 접속해서 캐싱된 뒤에는 인터넷이 없어도 앱이 열립니다 (단, 내용을 최신화하려면 온라인 상태에서 한 번씩 열어주세요). 데이터는 각 기기의 브라우저(로컬 저장소)에 저장되므로, 기기를 옮기실 땐 "내보내기/가져오기"를 이용해주세요.

기록과 백업

  • "기록" 화면에서 학습 세션별(그룹, 카드 수, 시각, 응답 비율) 기록을 확인할 수 있습니다. 5분 이상 활동이 없으면 세션이 종료됩니다.
  • "내보내기"로 전체 데이터를 JSON 파일로 저장하고, 다른 기기에서 "가져오기"로 불러올 수 있습니다.
